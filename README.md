# Zenra AI Viral Clips

Zenra AI Viral Clips is a Windows app that turns long videos into short clips for YouTube Shorts, Instagram Reels, TikTok and feed posts. Add a podcast, interview, vlog or sports video. The AI finds the strong moments, keeps the action in frame, adds captions and a title, and saves every clip ready to post.

- **Download for Windows:** https://github.com/bilalmelwana06/zenra-ai-viral-clips/releases/latest/download/ZenraAIViralClips.exe
- **Features, guide and pricing:** https://zenraai.com/tools/zenra-ai-viral-clips/
- Windows 10 and 11 (64-bit). 30-day free trial with every feature.

This repository holds the installer downloads (see Releases) and `version.json`, the small file the app reads to update itself.
